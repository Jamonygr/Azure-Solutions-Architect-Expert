# Eight-week study plan

The schedule assumes about eight hours each week. Adjust session length in your private `learner.config.yml`; the browser dashboard does not read that file and never synchronizes with it.

## Weekly cadence

### Learn

Complete each lab’s scenario, requirements, candidates, and five checkpoints. Stay in preview unless you independently have authorization, budget, and the required acknowledgements for a future live exercise.

### Retrieve

Answer the bank without the answer key. Mark uncertainty before reviewing a result; a lucky guess is still a remediation signal.

### Explain

Give a two-minute recommendation containing outcome, constraints, selected design, rejected alternative, failure behavior, evidence, and WAF consequences.

### Revisit

Schedule a second attempt at least two days later. Prefer the lowest objective/checkpoint cluster over immediately repeating the entire bank.

## Buffer and release checks

Reserve one session each week for missed work. In week eight, run the offline release gate from the pinned container before relying on generated pages. A passing gate establishes internal consistency, not live service availability, current quota, or tenant permissions.
